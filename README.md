# CodeAlpha Internship — Iris Flower Classification

## Project Overview
This project uses machine learning to classify Iris flowers into three species based on their sepal and petal measurements.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn
- Visual Studio Code

## Dataset
The project uses `Iris.csv`, containing flower measurements and species labels.

## Algorithm
Random Forest Classifier.

## Steps Performed
1. Loaded the Iris dataset using Pandas.
2. Checked the dataset and missing values.
3. Selected four measurement features.
4. Split the data into training and testing sets.
5. Trained the Random Forest classification model.
6. Evaluated the model using accuracy and a classification report.
7. Generated a confusion matrix and feature-importance graph.
8. Predicted the species of a new flower.

## Results
The model's accuracy is displayed when the Python program runs. The confusion matrix and feature-importance graph are saved as PNG images.

## How to Run
Install the libraries:

```bash
pip install pandas matplotlib scikit-learn
```

Run the program:

```bash
python iris_classification.py
```
